# goodreads-autopilot — Plan 02: Voice RAG

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans or subagent-driven-development. Steps use `- [ ]` tracking. **Status: BUILT & green** (implemented inline 2026-06-18).

**Goal:** Embed the user's existing reviews into a vector store and retrieve the stylistically nearest exemplars for a target book — the RAG layer that conditions generation on the user's voice.

**Architecture:** `Embedder` and `VectorStore` are `typing.Protocol`s. Retrieval logic (`build_index`, `retrieve`) depends only on those interfaces, so it is unit-tested with a deterministic `FakeEmbedder` + a pure-Python `InMemoryVectorStore`. The real `SentenceTransformerEmbedder` (bge-small) and `ChromaStore` ship behind the same protocols and are gated behind the optional `voice` extra (torch/chromadb).

**Tech Stack:** stdlib (math, sqlite3) for the core; `sentence-transformers` + `chromadb` as the `voice` extra. **Spec:** §6.3.

## Tasks (all complete)
- [x] **Task 1 — protocols:** `Exemplar` dataclass; `@runtime_checkable` `Embedder`/`VectorStore` Protocols. Test: `FakeEmbedder` satisfies `isinstance(..., Embedder)`.
- [x] **Task 2 — InMemoryVectorStore + cosine:** brute-force cosine search (flat search is correct for small corpora; ANN hurts recall at this scale per research). Tests: cosine identities, idempotent upsert.
- [x] **Task 3 — index build/retrieve:** `build_index` embeds every `is_empty = 0` review and upserts with `{book_id, rating}` metadata; `retrieve` embeds the query and returns top-k. Tests: empty→0, skips empty reviews, ranks relevant first, metadata `where` filter.
- [x] **Task 4 — real adapters (behind protocols):** `SentenceTransformerEmbedder` applies the bge query instruction to queries only; `ChromaStore` uses `PersistentClient` with `hnsw:space=cosine` and passes embeddings explicitly (not Chroma's built-in EF). Both lazy-import their heavy deps; both `omit`-ed from unit coverage (exercised by integration when the `voice` extra is installed). `pyproject` gained the `voice` extra, mypy `ignore_missing_imports` for the two libs, and coverage `omit`/`exclude_also`.
