# goodreads-autopilot — Plan 03: Generation

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. **Status: BUILT & green** (implemented inline 2026-06-18).

**Goal:** Turn retrieved voice exemplars + a target book into a review draft in the user's voice via Claude, with prompt caching and length validation.

**Architecture:** `generate_review` retrieves exemplars (voice layer), assembles a cached system prompt + per-book user turn, calls a `ChatClient`, and validates word count. The `ChatClient` protocol lets unit tests inject a `FakeChatClient`; the real `AnthropicChatClient` (anthropic SDK) sits behind it under the optional `generate` extra. **Spec:** §6.4.
